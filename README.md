# AXEN Novo Layout

Versao final organizada do projeto AXEN.

## Acesso principal

Abra `index.html`. Ele direciona automaticamente para:

`cliente/home.html`

## Acessos internos

- Cliente: `cliente/home.html`
- Administracao: `adm/dashboard.html`
- Aplicativo: `aplicativo/index.html`

## Estrutura

- `cliente`: Home, categorias e produto
- `adm`: Dashboard, produtos, pedidos, clientes e configuracoes
- `aplicativo`: experiencia mobile em telas separadas
- `assets`: CSS, JavaScript, imagens, logos e produtos
- `components`: header e rodape compartilhados

## Importante para publicar no GitHub Pages

Envie o conteudo inteiro desta pasta para o repositorio. Nao envie apenas os arquivos HTML soltos.

O arquivo `index.html` precisa ficar na raiz do repositorio publicado, junto das pastas `cliente`, `adm`, `aplicativo`, `assets` e `components`.
